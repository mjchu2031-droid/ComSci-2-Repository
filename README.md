# 2D Distance Calculator

## Description
This Python program calculates the straight-line (Euclidean) distance between two points $(x_1, y_1)$ and $(x_2, y_2)$ on a Cartesian plane using the standard distance formula:

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

By leveraging Python's built-in `math` library (`math.sqrt` and `math.pow`), the program efficiently computes precise distances with clear, modular structure.

## Execution Instructions
1. Make sure Python 3.x is installed on your computer.
2. Open a terminal or command prompt in the project directory.
3. Run the script with:
   ```bash
   python distance_calculator.py
