## Project overview

StudyTrack is a proposed Python application that helps students record and organize school tasks, assignments, and deadlines. It will save task records in a JSON file so that information remains available after the program closes.

The program is planned to support Create, Read, Update, and Delete (CRUD) operations and produce useful summaries such as the number of pending tasks, completed tasks, overdue tasks, and tasks grouped by subject or priority.

- `docs/testing_plan.md` — Proposed validation and testing checklist.
- `data/tasks.json` — Sample persistent data for planning and future development.

## Planned programming concepts

- **Functions and arguments:** separate functions for adding, listing, editing, deleting, searching, and summarizing tasks.
- **Iteration:** loops for displaying records and repeating the menu until the user exits.
- **Arrays/lists:** a list of task records loaded from JSON.
- **Programming libraries:** Python's `json`, `datetime`, and optionally `statistics` modules.
